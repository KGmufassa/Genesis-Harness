# Normalized UI Architecture Values

Use these values in Stage 4 template-selection and blueprint decisions.

## Navigation patterns

- `top-navigation`
- `sidebar-navigation`
- `bottom-navigation`
- `navigation-drawer`
- `split-navigation`
- `contextual-navigation`
- `tab-navigation`
- `breadcrumbs`

Navigation aliases:

- `top-navigation`: `top-nav`, `header-nav`
- `sidebar-navigation`: `sidebar`, `side-nav`
- `bottom-navigation`: `bottom-tabs`, `mobile-tabs`
- `navigation-drawer`: `drawer-nav`, `mobile-drawer`
- `tab-navigation`: `tabs`, `section-tabs`

- `responsive-grid`

- `card-grid`
- `data-table`
- `content-list`
- `master-detail`
- `split-pane`
- `form-layout`
- `settings-layout`
- `custom`

Layout aliases:

- `dashboard-grid`: `dashboard`, `metrics-grid`, `kpi-grid`

- `split-pane`: `split-view`, `resizable-pane`
- `form-layout`: `form`, `create-edit-form`
- `settings-layout`: `settings`, `configuration-layout`
