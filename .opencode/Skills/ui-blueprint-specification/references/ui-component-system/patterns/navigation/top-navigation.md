# Navigation Pattern — top-navigation

Use for public sites, commerce storefronts, or apps with a small number of primary sections.

Avoid when dense workspace navigation or many role-based sections are required.

Requires responsive collapse behavior, clear active state, keyboard access, and route targets for every nav item.
