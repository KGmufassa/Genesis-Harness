# Navigation Pattern — sidebar-navigation

Use for recurring authenticated apps with more than four primary sections or workspace-oriented tasks.

Avoid for simple marketing sites or mobile-only task tools.

Requires desktop active state, collapsed behavior when applicable, mobile drawer transformation, keyboard access, and route targets for every nav item.
