# Layout Pattern — settings-layout

Use when:

- users manage grouped preferences, account settings, integrations, permissions, or configuration

Requires:

- grouped sections
- save/cancel behavior
- permission-denied behavior
- dirty state behavior where applicable
- clear navigation between groups
