# Layout Pattern — form-layout

Use when:

- the page creates, edits, configures, or submits structured data

Requires:

- field groups
- validation behavior
- submit, cancel, reset, and unsaved-change behavior where applicable
- success and failure outcomes
- single-column mobile behavior
