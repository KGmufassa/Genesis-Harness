# UI Component Output Checklist

Every launch-critical page must have:

- purpose
- primary user goal
- page archetype
- layout pattern decision
- navigation role
- entry points and exit points
- primary action
- secondary actions when applicable
- sections
- component families
- interactive elements
- responsive transformation
- loading, empty, error, populated, and permission-denied states where applicable
- accessibility structure
- decision reasons and source references

Every selected layout pattern must include:

- selected pattern
- rejected patterns when plausible
- decision factors
- reasons
- source references
- desktop, tablet, and mobile behavior

Every template deviation must include:

- subject
- template default
- project choice
- reason
- source references
